<h1 align="center">PRIZM Evolution</h1>

<p align="center">
  <strong>Android-приложение для блокчейна PRIZM, объединяющее кошелёк, платежи, ферму и переписку в одном месте.</strong>
</p>

PRIZM Evolution создан для повседневной работы с PRIZM — от управления кошельками и переводов до NFC-платежей, My Farm и Meduza Chat.

## 💳 Кошелёк PRIZM

- Создание и импорт кошелька
- Несколько кошельков и быстрое переключение
- Баланс PRIZM
- Paramining на главном экране
- Копирование адреса
- Вход по короткому коду
- Сброс приложения

## 🔐 Key Store и защита кошелька

- Секретная фраза хранится в защищённом хранилище телефона
- Фраза привязана к адресу кошелька и зашифрована на устройстве
- Секретная фраза не отправляется в сеть
- Транзакция подписывается локально на телефоне
- В сеть отправляются данные, необходимые для передачи транзакции, а секретная фраза остаётся на устройстве
- Перед каждым платежом фразу вводить повторно не нужно
- Запись можно обновить или удалить
- Сохранённую фразу нельзя прочитать обратно в виде текста
- Копия секретной фразы остаётся только у владельца

## 💸 Prizm Pay

- Отправка и получение PRIZM
- История транзакций
- QR-коды для получения
- Сканирование QR
- Переводы с комментарием
- Шифрование комментариев
- Указание публичного ключа получателя

## 📲 NFC-платежи

Четыре действия простым касанием телефонов:

- Получить платёж
- Отправить платёж
- Выставить счёт
- Оплатить счёт

Без необходимости вручную вводить адрес получателя.

## 🌱 My Farm

- Просмотр своей фермы в сети PRIZM
- Слоты фермы
- Оплата слотов
- Напоминания по слотам
- Бесплатный лимит слотов

## 💬 Meduza Chat

Переписка, связанная с адресами PRIZM.

- Личные сообщения
- Общие комнаты
- Приглашения и QR-вход
- Никнеймы
- Сообщения на адрес
- Входящие сообщения
- Чёрный список
- Уведомления
- Настройка звука уведомлений

## 📊 Инструменты PRIZM

- Статус блокчейна
- Статус узла сети
- Суточная эмиссия
- TX VIZOR для поиска транзакций
- Конвертер PZM → RUB / USDT
- Адресная книга получателей

Курс можно использовать из CoinMarketCap или задать вручную для расчёта.

## ⚙️ Настройки

- Голосовые подсказки
- Фоновый звук на экране входа
- Настройка собственного узла сети
- API Scanner узлов
- Проверка обновлений
- Установка новой версии приложения из GitHub

## 🚀 Всё необходимое для PRIZM — в одном приложении

**Кошелёк. Платежи. NFC. My Farm. Meduza Chat. Инструменты блокчейна.**

PRIZM Evolution объединяет основные сценарии работы с экосистемой PRIZM в одном Android-приложении.
