<h1 align="center">PRIZM Evolution</h1>

<p align="center">
  <strong>Android-приложение для повседневной работы с PRIZM: кошелёк, платежи, ферма, переписка и сообщество.</strong>
</p>

PRIZM Evolution собрано для обычных дел в сети PRIZM: хранить монеты, переводить их, смотреть свою ферму, переписываться и следить за новостями сообщества.

## 💳 Кошелёк PRIZM

- Создание и импорт кошелька
- Несколько кошельков и быстрое переключение
- Баланс PRIZM
- Paramining на главном экране
- Копирование адреса
- Вход по короткому коду
- Сброс приложения

Секретная фраза хранится на телефоне. Подпись транзакции выполняется на устройстве.

## 💸 Prizm Pay

- Отправка и получение PRIZM
- История транзакций
- QR-коды для получения
- Сканирование QR
- Переводы с комментарием
- Шифрование комментариев
- Указание публичного ключа получателя

## 📲 NFC-платежи

Четыре действия простым касанием телефонов:

- Получить платёж
- Отправить платёж
- Выставить счёт
- Оплатить счёт

Адрес получателя для этого вводить не нужно.

## 🌱 My Farm

- Просмотр своей фермы в сети PRIZM
- Слоты фермы
- Оплата слотов
- Напоминания по слотам
- Бесплатный лимит слотов

## 💬 Meduza Chat

Переписка, связанная с адресами PRIZM.

- Личные сообщения
- Общие комнаты
- Приглашения и QR-вход
- Никнеймы
- Сообщения на адрес
- Входящие сообщения
- Чёрный список
- Уведомления
- Настройка звука уведомлений

## 👥 Community

- Новости блокчейна
- Чаты и каналы сообщества
- Ссылки PRIZM

## 📊 Инструменты PRIZM

- Статус блокчейна
- Статус узла сети
- Суточная эмиссия
- TX VIZOR для поиска транзакций
- Конвертер PZM → RUB / USDT
- Адресная книга получателей

Курс можно взять из CoinMarketCap или задать вручную.
