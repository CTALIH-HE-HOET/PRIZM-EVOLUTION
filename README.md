<h1 align="center">PRIZM Evolution</h1>

<p align="center">
  <strong>Android-приложение для повседневной работы с PRIZM: кошелёк, платежи, ферма, переписка и сообщество.</strong>
</p>

Криптография и формат транзакций взяты из исходников самого блокчейна PRIZM. Ключи и подпись считаются на телефоне по тем же правилам, что и в сети: сид-фраза никуда не отправляется, на узлы уходит только уже подписанная транзакция.

Надёжность сид-фразы складывается из двух частей. Сама фраза порождает ключи криптографией PRIZM. На телефоне она лежит в защищённом хранилище Android KeyStore: для каждого кошелька свой ключ, фраза шифруется на устройстве.

В переписке содержимое закрывается отдельно. Личные комнаты и зашифрованные сообщения шифруются на телефоне до отправки, поэтому в сеть уходит не открытый текст, а шифр. Расшифровать его можно только сид-фразой этого кошелька.

## Кошелёк

- Создание и импорт кошелька
- Несколько кошельков и быстрое переключение
- Баланс PRIZM и парамайнинг на главном экране
- Копирование адреса
- Вход по короткому коду
- Сохранение сид-фразы в Android KeyStore
- Сброс приложения

## Prizm Pay

- Отправка и получение PRIZM
- История транзакций
- QR-код для получения и сканирование QR
- Перевод с комментарием
- Шифрование комментария
- Проверка публичного ключа получателя

Подпись платежа выполняется на устройстве.

## NFC

Касанием двух телефонов, без ручного ввода адреса:

- Получить платёж
- Отправить платёж
- Выставить счёт
- Оплатить счёт

При контакте сид-фраза не передаётся. Подпись считается на телефоне отправителя, в сеть уходит только уже подписанная транзакция.

## My Farm

- Своя ферма в сети PRIZM
- Слоты, оплата слотов и напоминания
- Бесплатный лимит слотов

## Meduza Chat

Переписка, привязанная к адресам PRIZM.

- Общая комната
- Личные комнаты: приглашение и вход по QR
- Никнейм
- Сообщение на адрес и входящие: все, входящие, исходящие
- Адресная книга
- Чёрный список
- Уведомление о новом сообщении и свой звук

Ключ личной комнаты шифруется для вашего адреса. Сид в приглашение не кладётся.

## Community

Четыре ленты. Новости приходят из блокчейна PRIZM. Реклама подгружается из открытого репозитория, без обновления приложения.

**Новости** — лента сообщества, события вокруг PRIZM и жизнь приложения. Список читается из открытых сообщений в сети, карточка открывается по ссылке из сообщения.

**Чаты** — ссылки на чаты и каналы сообщества в Telegram, с карточками предпросмотра.

**Ссылки** — канал PRIZM Evolution, страница приложения, pzm.space и репозиторий PrizmCore.

**Реклама** — три вида объявлений: партнёры, размещения пользователей и специальные предложения. У карточки заголовок, текст и кнопки перехода.
